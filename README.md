# seeker
advance hacktool monitoring

🔍 System Monitor & Remote Access Tool
A powerful, feature-rich system monitoring and remote access tool built with Python and Flask. This application provides real-time system monitoring, remote command execution, audio/video streaming, and popup notifications through a modern web interface.

✨ Features
🎥 Real-time Monitoring
Live Camera Feed: Stream from connected webcams with adaptive quality

Audio Monitoring: Capture and stream audio from microphone

System Metrics: Real-time CPU, memory, disk, and network usage

Process Management: View and monitor running processes

💻 Remote Command Execution
Web-based Terminal: Execute system commands directly from the browser

Real-time Output: See command results instantly

Directory Navigation: Full cd command support

Cross-platform: Works on Windows, Linux, and macOS

Command History: Track previously executed commands

🔔 Notification System
Universal Popups: Show notifications on the host system

Multiple Methods: Windows Toast, Tkinter, platform-specific, and browser fallbacks

Remote Messaging: Send messages from web interface to host computer

🌐 Remote Access
Local Network Access: Access from any device on the same network

Internet Access: Ngrok tunneling for worldwide access

Secure Communication: Encoded email notifications

Responsive UI: Modern web interface that works on all devices

🚀 Quick Start
Prerequisites
Python 3.8 or higher

Webcam (optional, for video streaming)

Microphone (optional, for audio streaming)
